# CONFLUMIX

**The Multi-Mode Marketplace for Local Exchange.**

## Overview

CONFLUMIX is a unified multi-mode marketplace developed by a team of four third-semester BS Data Science students. It is being built to meet academic requirements across Software Engineering, Data Structures and Algorithms (C#), Introduction to Data Science (Python), and Computer Networks.

The platform integrates four distinct marketplace modes under a single, shared infrastructure:

1. **New Product Marketplace** – Buy and sell new products in a local exchange ecosystem.
2. **Reuse / Old Product Marketplace** – Facilitate the resale of pre-owned items to promote sustainability.
3. **Task & Soft Skills Marketplace** – Connect individuals for short-term tasks and skill-based services.
4. **Donation & Social Impact Network** – Enable donations and community-driven social initiatives.

## Technology Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** C#, ASP.NET Core Web API
- **Database & Authentication:** Supabase PostgreSQL and Supabase Auth
- **Analytics Service:** Python, FastAPI, Pandas, NumPy, Matplotlib, Seaborn
- **Version Control & Collaboration:** Git and GitHub
- **Frontend Deployment:** Vercel
- **Backend & Analytics Deployment:** To be decided later
